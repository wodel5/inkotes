# UI布局大改方案 - 单页笔记列表

## 目标
移除导航栏，改为类似小米创作的单页布局：顶部标题栏 + 全部笔记/文件夹瀑布流列表。

## 顶部标题栏设计
```
[锋页 Foledge]                          [+ 添加] [导入 ▼] [⚙ 设置]
```
- 左侧：应用标题"锋页 Foledge"
- 右侧按钮（从左到右）：
  - **+ 添加**：直接进入白板页面
  - **导入**：点击弹出下拉气泡菜单，两个选项"导入PDF"、"导入图片"
  - **⚙ 设置**：点击弹出设置对话框（不跳转页面）

## 主体内容
瀑布流网格，文件夹卡片和笔记卡片混合展示：
- **文件夹卡片**：显示文件夹图标 + 文件夹名称
- **笔记卡片**：显示预览缩略图 + 笔记标题（复用现有 PreviewCard）
- 文件夹在前，笔记在后
- 支持排序（复用现有 BrowseSortButton）
- 支持布局切换（复用现有 HomeLayoutButton）
- 点击文件夹进入文件夹层级（复用现有 BrowsePage 逻辑）
- 点击笔记直接进入编辑器

## 修改文件清单

### 1. `lib/data/routes.dart` — 简化路由
- 移除 `RoutePaths.prefixOfHome` 的子页面路由
- 简化为：`/` → 首页，`/edit` → 编辑器
- 移除 `HomeRoutes` 中的导航目的地（不再需要tab导航）
- 保留 `HomeRoutes.browseFilePath` 用于文件夹层级导航（作为 query param 传给首页）

### 2. `lib/pages/home/home.dart` — 重写首页
- 移除 `ResponsiveNavbar` 包装
- 新 AppBar：左侧标题 + 右侧操作按钮（添加/导入/设置）
- 正文区域：瀑布流网格，展示文件夹+笔记
- 内部维护一个 `currentPath` 状态来支持文件夹层级浏览（面包屑或返回）
- 合并 `RecentPage` 和 `BrowsePage` 的数据获取逻辑

### 3. `lib/pages/home/recent_notes.dart` — 删除
- 功能合入新的 `home.dart`

### 4. `lib/pages/home/browse.dart` — 删除
- 功能合入新的 `home.dart`

### 5. `lib/pages/home/settings.dart` — 改为纯 Widget
- 移除 `Scaffold` 和 `SliverAppBar` 包装
- 保留设置内容的 `SliverList` 部分
- 改为返回一个简单的 Widget（不含 Scaffold），供 Dialog 使用
- 保留 `showResetDialog` 静态方法

### 6. `lib/pages/home/whiteboard.dart` — 保持不变

### 7. `lib/main.dart` — 简化路由
- GoRouter 路由简化为：
  - `/` → `HomePage`
  - `/edit?path=...` → `Editor`
- 移除 `HomePage.recentSubpage` 等子路由

### 8. `lib/components/navbar/` — 整个目录删除
- `responsive_navbar.dart`
- `horizontal_navbar.dart`
- `vertical_navbar.dart`

### 9. `lib/components/home/welcome.dart` — 删除
- 不再需要空状态欢迎页

### 10. `lib/components/home/no_files.dart` — 删除
- 不再需要空文件提示

### 11. `lib/components/files/file_tree.dart` — 删除
- 仅在垂直导航栏展开时使用，导航栏移除后不再需要

### 12. 新增导入工具栏按钮组件
在 `home.dart` 中内联实现导入下拉菜单：
- 使用 `PopupMenuButton` 或自定义 `showMenu` 实现
- 两个选项：导入PDF、导入图片
- PDF导入逻辑复用 `NewNoteButton` 中的导入流程
- 图片导入逻辑复用 `Editor._pickPhotosWithFilePicker`

### 13. 新增设置对话框组件
使用 `showDialog` + `AdaptiveAlertDialog` 弹出设置对话框：
- 包含现有 `SettingsPage` 的所有设置项
- 对话框尺寸限制在合理范围（如 `constraints: BoxConstraints(maxWidth: 500, maxHeight: 600)`）

### 14. `lib/i18n/` — 更新翻译
- 移除不再使用的 tab 翻译（home.tabs.home/browse/whiteboard/settings）
- 更新首页标题翻译

### Step 1: 简化路由

## 验证方式
1. `dart analyze lib/` — 零 warning 零 error
2. 运行应用检查：
   - 首页显示文件夹+笔记混合列表
   - 标题栏显示"锋页 Foledge"
   - 添加按钮进入白板
   - 导入按钮弹出菜单可导入
   - 设置按钮弹出对话框
   - 点击文件夹进入子层级
   - 点击笔记进入编辑器
   - 返回文件夹层级正常
