# Lib 代码重构计划

## 目标
对 `lib/` 目录进行结构优化：拆分大文件、消除重复代码、规范文件命名和目录组织。**不改变任何功能逻辑**。

## 重构步骤

### 第1步：提取公共组件 `lib/components/common/`

**新建文件：**

1. **`lib/components/common/dock_button.dart`** — 统一的 DockButton
   - 合并 `toolbar.dart` 的 `_DockButton`、`home.dart` 的 `_HomeDockButton`、`trash_page.dart` 的 `_DockButton`
   - 提供 `icon` (Object) + `child` (Widget?) 两种构造方式
   - 保留 `selected`、`enabled`、`onPressed` 参数

2. **`lib/components/common/glassmorphism_dock.dart`** — 毛玻璃底栏容器
   - 提取 ClipRRect + BackdropFilter + Container 的通用模式
   - 接受 `child` 参数

3. **`lib/components/common/fallback_thumbnail.dart`** — 空缩略图占位
   - 合并 `preview_card.dart` 和 `trash_page.dart` 的 `_FallbackThumbnail`

**新建文件：**

4. **`lib/data/extensions/date_extensions.dart`** — 日期格式化工具
   - 提取 `_formatEditedDate()` 逻辑为共享函数

### 第2步：拆分 `pages/editor/editor.dart` (2160行 → ~7文件)

**提取方式：使用 Mixin 模式，EditorState mixin 多个功能类**

5. **`lib/pages/editor/editor.dart`** — 保留 Editor widget + EditorState（精简版）
   - 保留：initState, build, _initAsync, _loadCoreInfo
   - 保留：currentTool, savingState 等核心状态

6. **`lib/pages/editor/editor_gestures.dart`** — EditorGesturesMixin

   - `onInteractionEnd`, `updatePointerData`, `onHovering`, `onHoveringEnd`
   - `onStylusButtonChanged`, `onMoveImage`, `onDeleteImage`

7. **`lib/pages/editor/editor_history_ops.dart`** — EditorHistoryOpsMixin
   - `undo`, `redo`
   - 历史记录相关的辅助方法

8. **`lib/pages/editor/editor_file_ops.dart`** — EditorFileOpsMixin
   - `saveToFile`, `autosaveAfterDelay`, `cancelAutosaveAndMarkSaved`
   - `_renameFileNow`, `renameFile`, `_validateFilenameTextField`
   - `_pickPhotos`, `_pickPhotosWithFilePicker`, `paste`
   - `importPdf`, `importPdfFromFilePath`

9. **`lib/pages/editor/editor_export.dart`** — EditorExportMixin
   - `exportAsPdf`, `exportAsSba`, `exportAsPng`

10. **`lib/pages/editor/editor_page_ops.dart`** — EditorPageOpsMixin
    - `createPage`, `removeExcessPages`, `insertPageAfter`
    - `clearPage`, `clearAllPages`, `currentPageIndex`

11. **`lib/pages/editor/more_menu_overlay.dart`** — MoreMenuOverlay widget
    - 提取 `_MoreMenuOverlay` 和 `_MoreMenuOverlayState`

### 第3步：拆分 `pages/home/home.dart` (1109行 → ~5文件)
